# Hashthink Dashboard

A modern React dashboard application for managing and viewing financial transactions across multiple currencies.

## Features

- View transaction history with detailed information
- Filter transactions by currency (USD, IRR, INR)
- Search functionality across all transaction fields
- Download individual transaction records
- Mobile responsive design
- Currency-specific transaction views
- Real-time transaction status tracking

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- Tailwind CSS
- date-fns

## Getting Started

1. Clone the repository:
   
    git clone <repository-url>
    cd hashthink-dashboard
